# プライバシーポリシー

Link Radar for X（以下「本拡張」）は、X（Twitter）に表示されたリンクを分類して表示することのみを
目的としています。

## 要約

- 判定は利用者のブラウザ内で行い、URL・投稿テキスト・判定結果を**開発者のサーバーへ送信しません**。リンク先と中継サービスへの通信については以下に記載しています。
- 広告・トラッキング・アナリティクスは**一切行いません**。
- アカウント登録も、開発者への情報提供もありません。

## 処理する情報

- **画面内に表示されたリンクのURLと表示テキスト。** 判定のためにローカルで処理します。
- **そのリンク先のページ内容。** 有料記事か / 広告枠がいくつあるか / 登録が必要か / 短縮URLの
  行き先はどこか を判定するために、拡張機能のバックグラウンドで取得（fetch）します。
  取得時はCookieと参照元を送信しません（`credentials: "omit"` / `referrerPolicy: "no-referrer"`）。

  > URLだけでアダルト・注意対象・直ダウンロードと分かった場合は、追加のページ内容取得を省きます。
  > 短縮URLの場合、行き先を確認するための通信・HTTP転送は、この判定より先に行われることがあります。

  > リンク先の取得は、リンクを**クリックしなくても**行われます。接続先には利用者のIPアドレス、
  > リクエスト先のURLとアクセス時刻が伝わります。拡張機能は取得先サーバーによる記録を制御できません。
- **中継ページとその転送先。** `t.co` 等の行き先を確認するために接続します。
  LinkMistyのカードでは、ページ内に明示された同一サイトのクリック先と、その転送先にも接続します。
- **リンク集サービスの公開リンク一覧。** Instabio / linkbio.co 等は、サービスの公開CDN
  （`bio.linkcdn.cc`）からリンク一覧を取得することがあります。この取得ではサービスのページIDを使用し、
  Xの投稿本文や判定結果を送信しません。

処理するのは**Xの画面に実際に表示されたリンク**です。
閲覧履歴や他のタブの内容、フォーム入力、Cookie・認証情報は読み取りません。

## 権限が必要な理由

| 権限 | 用途 |
|---|---|
| `storage` | 判定結果のキャッシュと設定の保存 |
| `<all_urls>` | 上記「リンク先のページ内容」の取得 |

`<all_urls>`（すべてのサイトの読み取り）は広い権限ですが、本拡張がこれを使うのは
**Xの画面に出たリンク先を取得する**ためだけです。判定対象のドメインを事前に列挙することは
できない（誰がどのサイトのリンクを貼るか分からない）ため、この形を取っています。

ポップアップで「リンク先を取得して判定する」をOFFにすると、一般サイトの内容取得・リンク集の公開一覧取得・
LinkMistyのクリック先確認を停止します。有料媒体として登録されたサイトの判定、および行き先が読めないリンクや
既知の短縮URL・有料媒体への `t.co` 転送確認はOFFでも通信します。OFFはすべての通信を停止する設定ではありません。
URLや表示テキストから分かるアダルト・アフィ・招待・短縮・まとめ、および連投の判定は引き続き動作します。

## 保存

- 判定結果を高速化のため `chrome.storage.local` に**最大6時間**キャッシュします。
  閲覧履歴として蓄積することはありません。
- 設定（カテゴリのON/OFF等）は `chrome.storage.sync` に保存されます。
  Chromeにログインしている場合、Chromeの機能によって端末間で同期されます。
- **自分で登録したドメイン**（⚠️注意リスト / 判定から除外リスト）も同じ `chrome.storage.sync`
  に保存されます。利用者が入力したドメイン名なので、Chromeの同期機能を有効にしている場合は
  Googleアカウントを通じて端末間で同期されます（本拡張の開発者はこれを受け取りません）。
  同期させたくない場合は、Chromeの設定で拡張機能の同期をOFFにしてください。

## 第三者提供

URL・投稿テキスト・判定結果を開発者や広告・分析事業者へ提供しません。
機能に必要な通信先は、表示リンクの接続先、中継・転送先、リンク集サービスの公開CDNです。
Chromeの設定同期にはGoogleの同期機能を使用します。上記以外の共有は行いません。
